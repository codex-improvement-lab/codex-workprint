# Unified Profile examples

These three inputs are self-contained public projections from synthetic scenarios generated by three Codex Improvement Lab incubators. They are copied here so Workprint development, tests, packaging, and release checks never depend on sibling repositories.

- `continuity-archive-migration/profile.json` was generated by the Codex UX Lab Continuity Drill. It asks what still holds after a handoff.
- `goal-delta-offline-release/profile.json` was generated by Codex Proofline Goal Delta. It asks which proof lines stop carrying after an acceptance-contract revision.
- `context-receipt-observation-gap/profile.json` was generated by Context Governor. It asks what context was prepared, observed, excluded, or not observed.

The inputs are public projections, not raw task logs or attestations. Their `workprint/` directories are compiled by Codex Workprint itself; no sibling screenshot or renderer output is reused.
